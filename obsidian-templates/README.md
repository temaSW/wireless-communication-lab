# Шаблоны Obsidian

Эти файлы можно использовать со встроенным плагином Templates в Obsidian.

Рекомендуемая настройка Obsidian:

- Template folder location: `obsidian-templates`

Выбирайте шаблон под тип страницы:

- `research-or-project-*` - для `content/home/` и `content/projects/`
- `people-*` - для `content/people/`
- `students-*` - для `content/students/`
- `list-page-*` - для `content/publications/`, `content/patents/` и `content/media/`
- `news-item-*` - для новости внутри `content/news/ru.md` или `content/news/en.md`
- `navigation-*` - для `content/navigation/`

Если меняете страницу, обновляйте обе версии: `ru.md` и `en.md`.
